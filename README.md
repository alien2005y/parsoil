# Parsoil Bot
اپ اندروید: چند نفر را به ترتیب اولویت ذخیره می‌کند، صفحه را با فاصله دلخواه رفرش می‌کند، با باز شدن فرم هشدار می‌دهد و فرم + عکس‌ها را پر می‌کند. محصول و «مرحله بعد» با خودتان.

## نصب
1. این پوشه را در یک ریپوی گیت‌هاب بگذارید (شاخه main).
2. بعد از push، تب Actions خودکار APK می‌سازد و در Releases (مثلا v1.0.1) می‌گذارد.
3. APK را نصب کنید. در «تنظیمات» برنامه، `user/repo` را بنویسید.
4. هر push جدید = نسخه جدید؛ در برنامه «به‌روزرسانی برنامه» را بزنید.

## کار با برنامه
- افزودن نفر: مشخصات + عکس روی/پشت کارت (خودکار زیر ۵۰۰KB می‌شود). ▲▼ = اولویت.
- «شروع»: رفرش تا فرم باز شود → بوق + لرزش → پر شدن خودکار.
- «نفر بعد»: برای نفر بعدی صفحه را از نو باز و پر می‌کند.
- «بازرسی»: اگر فیلدی پر نشد، لیست idها را بفرستید تا اصلاح شود.

## نکته مهم
فیلدها با برچسب فارسی پیدا می‌شوند، چون HTML سایت در دسترسم نبود. تست نشده؛ اولین بار روی صفحه واقعی امتحان و با «بازرسی» تنظیم کنید.
